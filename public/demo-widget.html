Trang Web Demo Của Đối Tác

Thử nghiệm tính năng Orbit AI Website Widget

Giới thiệu

Đây là một trang web tĩnh dùng để kiểm thử tính năng nhúng Widget Chatbot của hệ thống Orbit AI. Bạn có thể tương tác với biểu tượng chat ở góc dưới cùng bên phải để bắt đầu cuộc trò chuyện.

Hướng dẫn test:

  • Bước 1: Chạy backend Laravel ở cổng 8000.
  • Bước 2: Mở tệp demo-widget.html này qua HTTP Server (ví dụ: http://localhost:3000/demo-widget.html).
  • Bước 3: Mở mã nguồn trang này và sửa lại giá trị BOT_ID_DEMO trong thẻ script bên dưới thành ID thực tế của Bot bạn muốn test.
  • Bước 4: Click vào icon và chat thử. Kiểm tra Console Network nếu có lỗi.
